History

DigiStudio was written in the early 1990s for an 8 MHz 80286. Software mixing played four sampled channels — even on the PC speaker. We were among the first. Same tech later ran in Pinball Fantasies: four-channel Amiga-style music mixed in software.

8 MHz. Four channels. No excuses.

Not a reimplementation — original DigiStudio / TSP / FLD source converted for modern systems. Same engine as DigiStudio 2.0 and PC Pinball Fantasies / Illusions. Kept original behaviour (and probably the bugs). UI rewritten.

Keys & effects

Keys

SPACE   stop if playing, else edit
ESC     stop
F5 / P  play
F8      stop
F1 / F2 octave
+/-     sample
TAB     channel
1–4     mute
Z..M / Q..P  piano
CTRL-O/S/V   file

Disk Op: load/save module + sample. SMP-ED: wave markers A/B, cut/trim/clr.
